### 模型注意事项

- USER 用一个预置用户实体同时支持卖家和买家，用户身份不拆成两表。
- BOOK_LISTING 一条对应一本实物书；RESERVATION_ORDER 每条代表一次具体预留并有唯一订单标识。
- 书籍对订单的历史联系为 **1 对 0..N**，但**同一书当前有效订单最多 1 条**。仅凭外键无法实施“只一条有效”“不可自购”以及取消对新订单的保护。
- 订单的 `created_at`、`cancelled_at` 作为**设计建议/可选属性**，不是实验一规定的必须展示或输入字段。
- 本阶段是**概念 ER**，**不等于**老师另行要求的“表间关系图”。
